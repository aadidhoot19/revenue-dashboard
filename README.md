# Revenue Dashboard

A production-ready static dashboard with a simple Express backend, login flow, signup, JWT auth, and salted password hashing.

## Features
- secure admin login with JWT token issuance
- public sign-up flow
- password validation and strong-password guidance
- salted password hashing using bcrypt
- protected dashboard API endpoints
- responsive built-in dashboard UI

## Default admin
- Email: admin@company.com
- Password: Admin@123!

## Install
```bash
npm install
```

## Run
```bash
npm start
```

Then open:
```text
http://localhost:3000
```

## API
- POST /api/auth/signup
- POST /api/auth/login
- POST /api/auth/admin-login
- GET /api/auth/me
- GET /api/dashboard/overview
- GET /api/dashboard/segments

## Security notes
- Passwords are stored as bcrypt hashes with salt automatically generated by bcrypt.
- JWT tokens are used for authenticated dashboard access.
- Rate limiting is enabled for login and API requests.
